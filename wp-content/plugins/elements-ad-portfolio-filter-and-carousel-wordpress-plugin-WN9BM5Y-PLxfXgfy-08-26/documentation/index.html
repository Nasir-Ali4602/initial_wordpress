AD Portfolio is an Wordpress Galleries Portfolio and Carousel Plugin. You can create a portfolio gallery with one click.
AD Portfolio includes 5 styles and 23 presets of portfolio.
  • Create Fully responsive portfolios
  • 5 Styles - 23 Presets
  • Create a Portfolio with shortcode button
  • Carousel
  • Css3
  • Cross browser
  • Compatible Wordpress 3.8, 3.7.x, 3.6.x and 3.5.x
  • Translation Ready (include file .po/.mo)

Step1: Installation

  1. Download the ZIP package from Codecanyon and Unzip it.
  2. Within the unzipped folder you will see a file named adportfolio1.2.zip - this is the Plugin itself.
  3. Log into your Wordpress Dashboard and click on Plugins.
  4. Next click on Install Themes then click on Upload.
  5. Click Add new -> Upload -> Browse then locate the file named adportfolio1.2.zip and click Install Now.
  6. After the theme has installed click on Activate Plugin and you are all set! New ADPortfolio Plugin is now installed!

Step 2: ADD Portfolio

  1. Go to pages or post
  2. ADD New/Edit Page:
    1. Push ADD Portfolio button in editor
    1. Check Portfolio
    2. Select Your Favorite Style
    3. Select Category (Multiple category is allowed)
    4. Number Post Load (Leave empty for all post)
    5. Link Position: overlay/image
    6. Link Format: yes/no
    7. Link Post/URL: yes/no
    8. Link Target: yes/no
    9. Title: yes/no
    10. Date: yes/no
    11. Text: yes/no
    12. Number Text Excerpt: insert number Excerpt
    13. Push insert Shortcodes
    1. Now the portfolio is created

Step 3: Set Number Posts

  1. Go to pages or post
  2. ADD New/Edit Page:
    1. Push ADD Carousel button in editor
    1. Check Carousel
    2. Select Your Favorite Style
    3. Select Category (Multiple category is allowed)
    4. Number Post Load (Leave empty for all post)
    5. Post Visible: insert post visible on load
    6. Carousel Autoplay - Insert timeout (0 for no autoplay)
    7. Carousel Carousel Navigation Active: yes/no
    8. Carousel Carousel Navigation Display Position: yes/no
    9. Carousel Carousel Navigation Position: yes/no
    10. Push insert Shortcodes
    1. Now the carousel is created
